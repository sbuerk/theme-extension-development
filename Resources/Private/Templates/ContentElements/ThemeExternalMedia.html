"theme_external_media" - a video of another site, embedded without loading anything from that site until the reader asks for it. The component is ".theme-embed" (Resources/Private/Scss/components/_embed.scss). **No iframe is in this markup.** The placeholder is a poster and a button, and "Resources/Public/JavaScript/theme.js" is what puts an iframe in its place once the button is pressed. That is the whole point of the element: opening the page opens no connection to the video's host, so nothing of it - not a cookie, not a fingerprint, not an entry in its logs - happens to a reader who never watches the video. "{embed}" is "Classes/DataProcessing/ExternalMediaProcessor.php": the URL the editor pasted, the provider it recognised, and the address of the cookieless embed. An unrecognised host leaves the last two empty, and this template then renders the placeholder with no button and keeps the link - which is the same page a visitor without JavaScript gets. See that class for what is recognised and why anything else is not embedded at all. The poster is the "image" of the element, a file of this installation. A thumbnail fetched from the provider would be a request to the host this element exists to avoid. The title of the iframe is "tx_theme_embed_title" - an iframe needs an accessible name, and "the video" is not one. It falls back to the heading of the element, and the button's label to a translated sentence, so neither is ever empty. {data.tx_theme_embed_title} {data.header}
