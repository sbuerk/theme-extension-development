"theme_accordion" - one native "details" per row of "tx_theme_list_items", on ".theme-accordion" (Resources/Private/Scss/components/_accordion.scss). Every "details" of one element shares one "name", which is what makes the group exclusive: the browser closes the open item when another one opens, with no script. The name is derived from the element's anchor, "c{data.uid}", for the same reason the tab ids of "ThemeTabs.html" are - two accordions on one page with the same name would close each other's items, because the browser groups by name across the whole document. No item is open initially, and there is no field to open one: an open first item is a choice about what a reader sees first, which the order of the items already expresses. The summary is the item's title as text, not a heading inside the "summary": the element is exposed as a button, and a heading within a button is flattened into its name by most assistive technology anyway. "item.data.text" is rich text on this relation (see "tt_content_theme_accordion.php"), hence "f:format.html".
