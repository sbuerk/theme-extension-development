Maps onto ".theme-quote" (Resources/Private/Scss/components/_quote.scss); markup matches that file's header comment. "header" and "subheader" are relabelled in Configuration/TCA/Overrides/tt_content_theme_testimonial.php to hold the attributed person's name and role, not a content-element heading - Partials/ContentElement/Header.html is therefore not reused here, and "header_layout" (part of the "headers" palette this CType's showitem reuses, alongside "date" and "header_link") has no effect on this markup: there is no heading to hide or re-level, only the attribution below. "header_position" and "tx_theme_header_style" are disabled for this CType in the page TSconfig. "tx_theme_quote_style" picks a modifier: (empty) a rule at the start of the quotation no modifier pull larger, between two rules "--pull" centred centred "--centred" Any other value renders the default, the rule of the frame modifiers in "Layouts/ContentElement.html"; "ContentElementContractTest" holds both modifiers to a rule of the stylesheet. The two styles carry a quotation mark, the "quote-left" icon of the set, in ".theme-quote__mark" before the quotation. It is decoration: "aria-hidden" on the slot, and the "blockquote" is what says that this is a quotation. The default has none, so every testimonial saved before the field existed renders as it did. The portrait is the one file of "image", as a ".theme-avatar" in the media slot ".theme-quote__portrait", first in the attribution. It is rendered only next to a name: there it is decoration - the name beside it says who it is, and the avatar contract of "_avatar.scss" gives a picture next to the visible name an empty "alt", set explicitly because "f:image" otherwise writes the alternative text of the reference, and a screen reader would read the name twice. Without a name the picture would be the only thing saying who is quoted, and would need an alternative text an editor may not have written, so it is left out rather than rendered unnamed. Cropped square on the server to 120 pixels, twice the 60 of "--large", so the browser gets no more than the slot shows; "cover" in the avatar still crops whatever was not processed.
