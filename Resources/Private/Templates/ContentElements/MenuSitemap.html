The "Sitemap" menu - the whole site, seven levels deep, from the site root. "ContentElements.typoscript", "tt_content.menu_sitemap", sets no "special" at all (the same default "MenuProcessor" uses for the site's own main navigation) and "levels = 7"; it has no "pages" field at all (see the core TCA), which is why nothing here reads one. This is a whole tree, not a flat list - "Partials/ContentElement/Menu" renders it with the same recursive "Item" section "Partials/Navigation/Main.html" uses for the site's own two-level main navigation, just for as many levels as "menu.children" actually goes.
