"uploads" is a file list, not a gallery, rendered as ".theme-file-list" (components/_file-list.scss). The fields are the core TCA of ".Build/vendor/typo3/cms-frontend/Configuration/TCA/Overrides/245-tt_content-content_type-uploads.php" on v13.4, and of the base TCA of EXT:frontend, "Configuration/TCA/tt_content.php", on v12.4 - the same fields and values on both: - "media" (type "file", no "allowed" restriction) and "file_collections" are both sources, wired into "FilesProcessor" the same way "collections" complements "references" for the image element - skipping "file_collections" here would make that field's tab do nothing. - "filelink_sorting"/"filelink_sorting_direction" order the merged list; "FilesProcessor" sorts natively via its "sorting"/"sorting.direction" options, so this stays a processor concern rather than a Fluid one. - "uploads_type" is the display type, and picks the modifier: 0 only the file name ".theme-file-list" 1 file name and extension icon ".theme-file-list--icon" 2 file name and thumbnail ".theme-file-list--preview" The icon is the one of the file type from the shipped set, "Partials/ContentElement/FileIcon.html". The thumbnail is made only for a file FAL classifies as an image ("file.type == 2", "TYPO3\CMS\Core\Resource\FileType::IMAGE" on v13.4, "AbstractFile::FILETYPE_IMAGE" on v12.4) - "f:image" cannot process a PDF or a text file, and the core's own label says "if possible" - and where it is not possible the icon of the file type stands in its square, so every row starts at the same place. Any other value renders the bare list, the rule of the frame modifiers of "Layouts/ContentElement.html". - "filelink_size" (checkbox) adds the size, formatted with "f:format.bytes", in every display type. - "uploads_description" (checkbox) adds the description of the file reference, when one was entered, in every display type. - "target" is passed straight through to the link. The icon and the thumbnail are decoration next to the link, not part of it: the file name is the text of the link and names the file with its extension, so the icon is hidden from assistive technology and the thumbnail has an empty "alt" - set explicitly, because "f:image" otherwise writes the alternative text of the reference. Escaping: the name, the size and the description are plain Fluid interpolation, escaped by default.
