"theme_cta" - a call to action on ".theme-cta" (Resources/Private/Scss/components/_cta.scss). Two fields pick the modifiers, each matched value by value, and anything else renders none - the rule of the frame modifiers in "Layouts/ContentElement.html", which "ContentElementContractTest" holds this file to: tx_theme_cta_width boxed "--boxed", a box centred in the column band "--band", across the whole column tx_theme_cta_tone (empty) the surface fill, no modifier accent "--accent", the tint of the accent band inverse "--inverse", the other appearance placeholder "--placeholder", no fill, dashed frame "tx_theme_icon" is a large icon above the heading, picked by the editor, rendered with "optional": a name a later Font Awesome version dropped costs the icon, not the page. It is decoration - the heading says what the call to action is about - so the slot is "aria-hidden". The heading is "header" at the level of "header_layout", h2 by default: a call to action is a section of a page, not its title, unlike the hero. "header_layout" 100 hides it, as everywhere. The two links are the "theme_link" palette and the "theme_secondary_link" palette, both rendered by "Partials/ContentElement/LinkButton.html" - the second handed its four columns as the arguments the first fills, so the style and the icon of either link are decided by one set of cases. Either link may be empty; with neither, the element renders no row of actions. "bodytext" is rich text (the "columnsOverrides" of the type), so the text is a "div" of paragraphs rather than the "p" a plain text would take.
