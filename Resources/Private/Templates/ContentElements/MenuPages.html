The "Pages" menu - one link per page the editor selected in "pages", nothing more. "special = list" in "ContentElements.typoscript" ("tt_content.menu_pages") is what tells "MenuProcessor" to fetch exactly those uids rather than a rootline position; see that file's comment for what an empty "pages" selection falls back to. Rendering itself is the shared "Partials/ContentElement/Menu" - this element differs from "menu_subpages" only in the TypoScript "special", not in anything Fluid needs to know, so neither "showAbstract" nor "showDate" is passed. "layout" picks the rendering: 1 cards, 2 thumbnails - both "Partials/ContentElement/MenuCards.html", fed by the second "MenuProcessor" of the element, which adds the page media (see "lib.themeMenuWithPageMedia" in "ContentElements.typoscript") - and anything else the list. The page TSconfig offers the field on this CType and on "menu_subpages", where the same three values apply.
