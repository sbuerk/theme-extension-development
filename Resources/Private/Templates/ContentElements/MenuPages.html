The "Pages" menu - one link per page the editor selected in "pages", nothing more. "special = list" in "ContentElements.typoscript" ("tt_content.menu_pages") is what tells "MenuProcessor" to fetch exactly those uids rather than a rootline position; see that file's comment for what an empty "pages" selection falls back to. Rendering itself is the shared "Partials/ContentElement/Menu" - this element differs from "menu_subpages" only in the TypoScript "special", not in anything Fluid needs to know, so neither "showAbstract" nor "showDate" is passed.
