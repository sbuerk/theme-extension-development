"theme_text_icon" - the heading, the rich text and the link of the element beside one icon of the set, on ".theme-media-object" (Resources/Private/Scss/components/_media-object.scss). --- Three axes, one modifier each ---------------------------------------- tx_theme_icon_position start, end, top --start, --end, --top tx_theme_icon_shape plain, square, circle --plain, --square, --circle tx_theme_icon_size md, lg, xl --md, --lg, --xl Every value is matched by an "f:case", and anything else - an empty value, an import, a value an older record carries - renders the first value of its axis, which is also the TCA default. The modifier is always written, so a block names its layout in full. "ContentElementContractTest" holds every class written here to a rule of the compiled stylesheet. --- The icon --------------------------------------------------------------- "tx_theme_icon" is a name an editor picked, rendered with "optional": a name a later version of the set no longer has costs the icon, not the page. The icon is rendered into a variable first, and the slot only when that produced markup, so an element without a usable icon is its text alone rather than an empty tile. The variable holds what "theme:icon" renders - the markup of a file of the set, never a value of the record - hence "f:format.raw" on output. The slot is decoration and "aria-hidden": the heading and the text say what the icon shows. --- The body --------------------------------------------------------------- The heading goes through the shared header partial inside the body, so it sits beside the icon and "header_position" and "tx_theme_header_style" apply. "bodytext" is rich text on this type, hence "f:format.html"; the link is the "theme_link" palette, rendered by "LinkButton" as everywhere.
