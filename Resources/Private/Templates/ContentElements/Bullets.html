The name comes from a record, so it is rendered with "optional": an icon a later version of the set no longer has costs the icon, not the page. With no icon picked the layout has nothing to show, and the list renders as layout 0 rather than as a column of empty marker slots. --- The definition list --------------------------------------------- Always ".theme-dl--horizontal": terms and descriptions side by side from "bp.$md" up, stacked below it. "layout" does not apply to it. Each line is a row of "CommaSeparatedValueProcessor", split at "|" with the enclosure '"', as fluid_styled_content splits it: the first cell is the term, every further non-empty cell a description of it. A line without "|" is a term without a description.
