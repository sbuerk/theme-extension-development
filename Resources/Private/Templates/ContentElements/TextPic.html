"textpic" is text plus the "image" field - the same shape "FilesProcessor" and "GalleryProcessor" already give the image element, see the comment on "tt_content.image" in "ContentElements.typoscript". This template only adds the "bodytext" and decides where it sits relative to the gallery. "imageorient" resolves to a vertical position of "above", "below" or "intext" and a horizontal one of "left", "center" or "right" - "GalleryProcessor" has already made that translation, and the gallery partial reads it into the "theme-gallery--{vertical}"/"--{horizontal}" classes. "below" is the only vertical value that changes the DOM order here: "above" and "intext" both put the gallery first, which is also where the float has to be for the text after it to flow around it. The gallery partial adds "--float-start"/"--float-end" (and "--nowrap") for "intext", see "components/_gallery.scss".
