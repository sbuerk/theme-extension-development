The "Recently updated pages" menu - "special = updated" in "ContentElements.typoscript" ("tt_content.menu_recently_updated") sorts the tree beneath "pages" (or, empty, the current page) by "SYS_LASTCHANGED" descending, and each item shows that date beneath its link. "SYS_LASTCHANGED" needs no "dataProcessing" of its own either - it is the very field the query already sorts by, on the same "item.data" page row "menu_abstract" reads "abstract" from. Passing "showDate: 1" into the shared partial is the only thing this template does differently from "menu_pages".
