"textmedia" is the same shape as "textpic", the only difference is the source field: "assets" ("common-media-types", not restricted to images) instead of "image" - see the core TCA in ".Build/vendor/typo3/cms-frontend/Configuration/TCA/Overrides/230-tt_content-content_type-textmedia.php" and "tt_content.textmedia" in "ContentElements.typoscript" for where that field is wired into "FilesProcessor". "GalleryProcessor" does not care which field the files came from. "imageorient" resolves to a vertical position of "above", "below" or "intext" and a horizontal one of "left", "center" or "right", already computed by "GalleryProcessor" and read by the gallery partial into the "theme-gallery--{vertical}"/"--{horizontal}" classes. "below" is the only vertical value that changes the DOM order here: "above" and "intext" both put the gallery first, which is also where a stylesheet has to find it to float it beside the following text for "intext" - see "components/_gallery.scss" for why the position modifiers are structural only for now.
