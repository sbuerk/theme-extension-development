Backend layout "two_columns_wide" (Configuration/PageTsConfig/BackendLayouts/TwoColumnsWide.tsconfig) - the same two slots as "Templates/Page/TwoColumns.html", with the first column twice as wide as the second. Only the modifier differs, and the file exists anyway: a site package overrides one layout without touching the other, which is the same reason "Start.html" is a file of its own although it renders what "Content.html" renders. See "TwoColumns.html" for why the grid sits inside ".theme-page__main" rather than on it, and why each column is wrapped.
