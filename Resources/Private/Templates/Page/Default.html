Backend layout "default" (Configuration/PageTsConfig/BackendLayouts) - the "main" content slot only, colPos 0, per the step 2 contract's column layout table. No "stage", no "sidebar": this template defines neither the "Aside" section nor renders "Partials/Page/Stage.html", so "Layouts/Default.html" emits no ".theme-page__aside" and there is nothing above the main content. The only page template that renders the page title itself. "default" is the bare layout: it has no "stage" slot, so nothing editorial is guaranteed to carry a heading, and a page with no content yet would otherwise render an empty main element with no indication of which page it is. That case is common in a theme meant for extension development. The layouts that do have a stage deliberately leave the heading to the content placed in it - emitting one here as well would give those pages two first-level headings.
