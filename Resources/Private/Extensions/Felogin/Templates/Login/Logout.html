The logout form of EXT:felogin on the form contract of the theme - the counterpart of "Login.html" next to it, see there and "Configuration/TypoScript/Felogin.typoscript". It sends what felogin's own template sends: "logintype=logout" and, when redirects are disabled, "noredirect". "actionUri" is passed through as felogin's v13 template passes it: on TYPO3 v13 the logout action assigns the logout redirect target there, and the form posts to it. TYPO3 v14 removed the variable and redirects through an event instead (Breaking #103910); there "{actionUri}" is unset, and the form ViewHelper builds the action as it does without the argument. One template for both, with no condition. felogin labels the user name with a "label" pointing at the submit button, which names the button "Username" for a screen reader. The name is a fact about the session, not a field, so it is a paragraph here, and the button keeps its own label "Logout".
