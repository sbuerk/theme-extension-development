The heading of one item inside a content element, one level below the element's own heading. "Partials/ContentElement/Header.html" renders the element's heading at "header_layout" 1 to 5, h2 for 0, and nothing at all for 100 or an empty header. An item heading continues that outline: the level after the element's, and h2 when the element shows no heading - the item then sits directly below whatever heads the page. Level 5 has h6 below it, which is as deep as HTML goes. Arguments: "data" (the content element record), "class", "title", and optionally "link" with "linkClass": a TYPO3 link reference - the value of a TCA type=link field - which turns the title into "f:link.typolink" of that class, inside the heading. The section "Title" is written on one line on purpose: whatever whitespace it holds ends up inside the heading.
