The icon of a file type, by the extension of the file: the "file-*" icons of the shipped Font Awesome solid set, and "file" for every extension without one of its own. Rendered by "Templates/ContentElements/Uploads.html" in front of every file of the display types "file name and icon" and, where FAL has no thumbnail to offer, "file name and thumbnail". Called with "extension", the lower case extension FAL reports for the file ("AbstractFile::getExtension()" lower-cases it on v13.4 and v14.3), so "REPORT.PDF" is a PDF as well. By extension rather than by MIME type: the extension is what the name in the link shows, and an icon that disagreed with it - a ".csv" FAL detected as "text/plain" drawn as a text file - would contradict the text next to it. One case per extension, each with its icon written out, so "IconUsageTest" holds every one of them to the shipped set and the icon table of the styleguide to this file. Decoration only: the caller wraps it in an "aria-hidden" slot, and the file name in the link is what names the file.
