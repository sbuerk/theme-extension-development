The gallery of a content element, as "GalleryProcessor" computed it: rows, columns, a position, and a width and a height for every media element. The processor has already decided the column count from "imagecols", so the stylesheet must not impose one of its own - the editor's "Number of columns" would stop meaning anything. The count is exposed as a data attribute for CSS that wants to react to it. The width and height are rendered as attributes rather than left to CSS. They are what lets the browser reserve the box before the image has loaded, which is the difference between a page that settles and a page that jumps.
"alt" and "title" are not passed: the view helper takes them from the "alternative" and "title" properties of the file reference by itself, and passing an empty string would suppress that fallback rather than fill it in.
