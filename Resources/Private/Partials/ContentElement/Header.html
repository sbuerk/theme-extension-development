The header of a content element. "header_layout" carries the heading level, and the value 100 means "do not display" - the convention of the core TCA offered in the backend, so a theme ignoring it would render headers an editor had hidden. Two fields decide how the header looks rather than where it sits in the outline, and both become modifiers: header_position center ".theme-content-element__header--center" right ".theme-content-element__header--end" left ".theme-content-element__header--start" tx_theme_header_style display ".theme-display", the text role h1-h5 ".theme-content-element__heading--h1" ... "right" and "left" are the values of the core select and map to the logical edges: the stylesheet is written in logical properties, and a header an editor put at the end of the line stays at the end of it in a right-to-left language. The visual size is independent of the level on purpose: the level says where the heading sits in the outline, the style how loud it is. The display size reuses the text role ".theme-display" rather than repeating its metrics. Values outside those lists render no modifier, the same rule as the frame modifiers of "Layouts/ContentElement.html".
