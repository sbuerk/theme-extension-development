The icon of one ".theme-alert" kind, for the "theme-alert__icon" slot. The alert contract (Resources/Private/Scss/components/_alert.scss) makes the icon, not the colour, what tells the kinds apart - forced colours drop the tint and the accent and leave only this. One icon of the Font Awesome Free solid set per kind, the same six "Partials/Styleguide/Boxes.html" shows: info circle-info success circle-check warning triangle-exclamation danger circle-xmark tip lightbulb note note-sticky An unknown kind gets the note's icon, the same fallback "ThemeNotice.html" applies to the kind itself. The slot is "aria-hidden" already, so the icons carry no label.
