The site footer, sitewide chrome rendered unconditionally by "Layouts/Default.html" for every page template. This file picks one of two arrangements and renders nothing itself, the same shape "Partials/Page/Header.html" has and for the same reasons - read that file's comment for both of them, including why the value of the setting never becomes part of a partial path. WHICH ONE IS A SITE SETTING: "theme.footer.variant", declared in "Configuration/Sets/ThemeExtensionDevelopment/settings.definitions.yaml" and, with the same default, as a TypoScript constant. See "docs/architecture/site-settings.md". The two share everything below the band: "Page/Footer/Body.html" is the four content columns and the meta row, and both variants render it. What "newsletter" adds is a band above them.
