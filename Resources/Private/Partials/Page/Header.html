The site header, sitewide chrome rendered unconditionally by "Layouts/Default.html" for every page template. This file picks one of four arrangements and renders nothing itself. Each one is a partial below "Page/Header/", the shared pieces are "Brand", "Controls" and "Action" next to them, and "layout/_site-header.scss" carries a modifier per variant. That is the shape the rule about version aware code asks for, applied to a different axis: a difference that changes the whole block is a second file, never a condition sprinkled through one. WHICH ONE IS A SITE SETTING. "theme.header.variant" - declared in "Configuration/Sets/ThemeExtensionDevelopment/settings.definitions.yaml" and, with the same default, as a TypoScript constant in "constants.typoscript" for a site that takes the theme through the classic static include - on TYPO3 v12, which has no site sets, every site. "Page.typoscript" reads the constant into "headerVariant"; see the comment there for why it is a variable rather than something the template looks up. THE VALUE NEVER BECOMES PART OF A PATH. "f:render partial="Page/Header/ {headerVariant}"" would be shorter and is exactly the shape that turns an editable setting into a file system lookup. The switch names all four partials as literals, so a value nothing matches renders the default one rather than reaching for a file. --- Why none of the three other variants re-opens the header budget ---- The one-row header is measured: with seven top level entries the title holds its line at 1280 and at 1024 while the menu wraps, and at 800 the title wraps to three lines with no sideways scroll - "Tests/Acceptance/frontend.spec.ts" holds all four measurements, and "layout/_site-header.scss" explains the 50% cap that arranges them. A variant that added a control to that row would have to be measured again. None of them does. "centred" gives the title a row of its own, "actions" gives the navigation one, and "two-tier" moves both controls out of the title's row into a meta row above it - so the row the cap governs holds fewer things in every variant, not more. The call to action of "actions" sits in the row the navigation left.
