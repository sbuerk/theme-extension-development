The site header, sitewide chrome rendered unconditionally by "Layouts/Default.html" for every page template. Markup contract: docs/development/component-library.md#layout. Main navigation: "Partials/Navigation/Main.html" renders ".theme-nav-main" itself, including its own empty guard, so it is rendered unconditionally here the same way the brand link is - the partial decides whether anything actually appears. ".theme-site-header__actions" is the slot at the end of the header the contract documents; it holds the appearance/palette switcher, "Partials/Page/AppearanceSwitcher.html", which is hidden by its own CSS until a script has run - see that partial's header comment.
