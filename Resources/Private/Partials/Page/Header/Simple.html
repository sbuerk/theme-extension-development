Header variant "simple", the default: the site title, the main navigation and the controls in one row. This is the header the theme had before the variants, unchanged - which is the point. It carries no modifier class, so a site that never touches "theme.header.variant" gets exactly the markup, the stylesheet rules and the measured behaviour it had before, and the four acceptance tests that measure the row keep measuring it. Main navigation: "Partials/Navigation/Main.html" renders ".theme-nav-main" itself, including its own empty guard, so it is rendered unconditionally here the same way the brand is - the partial decides whether anything actually appears.
