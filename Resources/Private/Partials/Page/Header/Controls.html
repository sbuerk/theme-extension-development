The controls slot of the site header: the language dropdown and the display settings, in that order, shared by all four header variants. ".theme-site-header__actions" is the slot the markup contract documents - see "docs/development/component-library.md#layout". It keeps that name in every variant, including "two-tier", where it sits in the meta row rather than beside the navigation: the class names the slot, not the row. The language menu is in a dropdown so the header row keeps its width whatever the site's languages are called. The guard counts the languages rather than testing the menu for emptiness. "LanguageMenuProcessor" defaults "special.value" to "auto" and returns early only for a site with no language at all, so a one language site produces a menu of exactly one item - the language already being read. That is a control offering the reader nothing, so the whole dropdown is left out below two languages. The dropdown itself needs no script and is never hidden behind "data-js": it is a "details", and the browser opens and closes it. What "Resources/Public/JavaScript/theme.js" adds is the dismissal only - Escape, a click outside, and focus leaving the control. See "Partials/Page/Dropdown.html". It sits before the display settings: the language is a property of the page, the settings are a property of the reader.
