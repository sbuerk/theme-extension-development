Header variant "two-tier": a tinted meta row carrying the controls, and the site title with the main navigation in the row below it. The meta row is where the language dropdown and the display settings go, which is what makes this variant roomier than the default rather than tighter: the row the measured 50% cap governs holds the title and the menu and nothing else here - see "Partials/Page/Header.html". The meta row is a "div", not a second "nav" or a "header": it is a slot holding two controls that name themselves, and an extra landmark would show up in a screen reader's landmark list with nothing useful to say. The header element itself is the landmark, and there is exactly one of it in every variant.
