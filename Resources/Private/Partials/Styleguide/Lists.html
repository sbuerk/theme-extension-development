Lists

Unstyled, and a nested list

--unstyled drops the marker and the indent of the list it sits on, and of that list only: a list nested in one of its items keeps the element baseline, markers and all, unless it carries the class itself.

  • An item with neither marker nor indent.
  • An item holding a nested list:
    • The nested list is a plain one.
    • It keeps its markers.
  • The last item.

Inline

One row that wraps, with a hairline between the items - a border, not a character, so there is nothing for a screen reader to read out between them and nothing that changes with the font.

  • Site set
  • Static include
  • Styleguide
  • Forms

Check marks

One marker for every item: the check of the icon set, which the stylesheet paints through a CSS mask in the success accent, so a list needs no markup per item. It has the same shape in every font, and under forced colours it is drawn in the text colour.

  • Every component reads its values through a token.
  • An item long enough to wrap shows that the text of every line stays aligned past the marker instead of running back under it, which is what a hanging marker is for.
  • Both appearances and every palette are tested.

Icons

An icon per item, from the theme-list__icon slot, rendered by the icon ViewHelper: one em square and centred on the first line, in the primary accent, and hidden from assistive technology because the text of the item is its content.

  • Configuration below Configuration/Sets/.
  • Templates below Resources/Private/, the compiled stylesheet below Resources/Public/.
  • Tests below Tests/.

Columns

The items flow into two or three columns where each column gets at least 12 rem, and into fewer where it does not - a phone gets one. The order runs down the first column before the second, and no item is split across two.

Divided

No markers, and a hairline between the rows instead - for a list whose items are records rather than points of an argument.

Description list

Stacked, the component differs from the element baseline in one thing: a description is not indented. A term may carry several descriptions.

Site set
The configuration a site depends on in its own configuration.
Static include
The same TypoScript, included through a template record.
Kept for installations that do not use site sets.

Horizontal, the terms take a column of their own from the medium breakpoint up. A description of several paragraphs and a nested list stay in the second column.

Appearance
Light, dark, or whatever the operating system prefers.
Palette

One of five sets of accents; neutrals stay the same in all of them.

The last paragraph of a description drops its bottom margin to the rhythm of the grid.

Nested
Inner term
A description list inside a description.

--truncate keeps every term on one line and cuts it with an ellipsis. It is opt-in, for terms that are identifiers or paths - text cut off by default would be text nobody asked to hide.
