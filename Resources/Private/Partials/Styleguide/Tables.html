Styleguide section "tables" - ".theme-table" and its modifiers. Contract: "Resources/Private/Scss/components/_table.scss". Every specimen is the wrapper of that contract - "tabindex=0" plus "role=region" plus an "aria-label", the W3C APG scrollable-region-focusable pattern - around a ".theme-table". Each wrapper carries a label of its own, so the regions of this section can be told apart when tabbing through them. The table without a class, the one rich text produces, stays in Typography: it is the element baseline, and this section is what the component adds to it. "--hover" cannot be shown in a still picture; its specimen says so, and its colour is recorded in DESIGN.md "Table rows". "--sticky-header" needs a table taller than the wrapper, so its specimen has enough rows to scroll.

Tables

The component

The component adds the frame and the scrolling region around the table. The wrapper is focusable and labelled as a region: it scrolls horizontally so the page never has to, and a box that scrolls without a tab stop of its own cannot be reached by keyboard at all. Focus it and the arrow keys scroll it, with no script involved. Header cells sit on the surface tint above a strong rule, rows are separated by a hairline, a row header is set at the medium weight, and a cell holding a number takes the one helper class there is, which aligns it to the end and sets it in figures of equal width.

Striped rows, striped columns

--striped puts every other row on the surface tint, --striped-columns every other column. Both stripe by position, so a row added or removed keeps the pattern. A stripe is a reading aid rather than a state: under forced colours it goes with every other fill.

Hover

--hover tints the row under the pointer with the primary accent, mixed into the background - move the pointer over the rows below; a still picture of this page cannot show it. Under forced colours the hovered row is drawn in the system highlight colour, because a fill alone would be repainted away.

Bordered, borderless, compact

--bordered adds a hairline between the columns, --borderless removes every rule - the header, the rows and the groups - and leaves the header's tint to set it apart. --compact halves the padding of every cell.

Sticky header, caption below

--sticky-header keeps the header row in view while the wrapper scrolls through a table taller than it - the wrapper gets a height for that, and it is still the one focusable region, so the arrow keys scroll it both ways. --caption-bottom moves the caption below the table.

Combined with --bordered, groups and totals, as below, every rule is drawn once: separated borders do not merge where two cells meet, so the sticky header takes the column rule from one side of it and the hairline from above a group or totals rule.
