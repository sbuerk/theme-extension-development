Styleguide section "data-display" - ".theme-avatar", ".theme-tag-list", ".theme-progress" and ".theme-meter": the components that show a value or a person rather than a passage of content. Key and value pairs are the description list, in "Lists". Contracts: "Resources/Private/Scss/components/_avatar.scss", "_tag.scss", "_progress.scss" and "_meter.scss". Literal markup only, specimen copy in English. Portraits are inline SVG data URIs, like the images of "Media": a specimen has no file reference to render, and the theme renders with no network. The tag icon is the theme:icon ViewHelper, as every icon of the theme. Ids are prefixed "sg-data-", so no id of this section meets one of the page chrome or of another section.

Data display

Avatar

A portrait in a circle, in three sizes of the spacing scale - small, the default and large - and square with --square. The name is the alt of the image.

Without a portrait, the initials - text, not an icon, set at 40% of the size. The name is the aria-label of the avatar, and the letters themselves are hidden from a screen reader.

CP CP CP DD

Next to the person's name the avatar is decoration: the image takes an empty alt, and the initials neither a role nor an aria-label, so a screen reader reads the name once.

Avatar group

A list of avatars that overlap, each ringed in the colour of the page so its edge reads against the next. The last item counts the people left out. On a card or a band, re-point --theme-avatar-group-ring-color to the colour the group sits on.

Tags

Keywords, as a list that wraps. A plain tag is text on the surface tint; a linked tag is underlined as well as drawn in the accent, so it is not told apart by colour alone, and turns its hairline to the accent on hover. An icon before the label is optional decoration.

Progress

The native progress bar, labelled like a control, with its value written out as a hint. The track is edged in the strong border colour: it is the only thing showing how far the bar could go, a graphical object held to 3:1. Without a value the bar is indeterminate and shows the empty track.

Meter

A measurement within a known range. The browser sorts the value into a region from low, high and optimum, drawn in the success, the warning and the danger colour. The colour is not the message: the hint says in words what the region means, and the meter references it.
