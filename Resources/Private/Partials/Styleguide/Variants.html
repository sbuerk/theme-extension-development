Styleguide section "Layouts and variants": the layouts an editor picks for a content element, drawn from the component each one maps onto - the text in columns of the text element, and the file list in the three display types of the file links element. A section of its own rather than more specimens in "Typography.html" and "Boxes.html": these are the choices of a content element's form, shown together, one specimen per value an editor can pick. The components they are made of keep their own specimens in their own sections. Literal markup and English copy, like every section: nothing here is driven by a record, a data processor or a TypoScript object.

Layouts and variants

Text in columns

Contract: Resources/Private/Scss/components/_text.scss, ".theme-text--columns" - the layout "Columns" of the text element. Long enough to break into two columns at the width of the specimen, with a heading that has to stay with its paragraph and a quotation that moves to the next column whole.

The text is set in two columns wherever each can be at least thirty characters wide, and in one where it cannot. The markup inside is ordinary rich text; only the block around it carries the modifier.

A hairline in the decorative border colour separates the two columns. A paragraph keeps at least two of its lines on either side of a break.

A heading stays with its text

The heading above never ends a column on its own: it moves to the next one together with the start of this paragraph.

A quotation, a table, a code block and every item of a list move to the next column whole rather than being cut in two.

The first element starts at the top of the first column, level with the second, because its top margin is dropped.

File list

Contract: Resources/Private/Scss/components/_file-list.scss - the three display types of the "File Links" element: the file names alone, with the icon of the file type, and with a thumbnail, where a file with no thumbnail gets its icon in the thumbnail's square. The links point at "#": a specimen links to no file. The thumbnail is an inline SVG data URI in an "img", for the reason "Boxes.html" gives: no image can be referenced from a Fluid partial without a FAL record.

Hero layouts

Contract: Resources/Private/Scss/components/_hero.scss, the layouts of the hero elements next to "--media": "--image-end", "--centred", "--screenshot" and "--bordered". The default - the image at the start - is the "--media" specimen of "Boxes.html". Titles are "h4", for the reason "Boxes.html" gives. The screenshot is the one layout whose image follows the text in the markup.
