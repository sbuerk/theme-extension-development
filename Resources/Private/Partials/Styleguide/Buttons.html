Buttons

Variants

Book a demo .theme-button — the filled default. It marks the one action a view most wants taken, which is why a view should carry exactly one of them.
Compare editions .theme-button--secondary — the accent moves from the fill to the text and the border. For an alternative that has to stay clearly available without competing with the filled action next to it.
.theme-button--ghost — no border and no fill, drawn in the secondary text colour. For a tertiary action such as dismiss or cancel, sitting beside a real one.
.theme-button--danger — destructive. Deliberately the same shape as the default: the colour carries the warning, and a different shape would only make it harder to recognise as a button at all.
Read the changelog .theme-button--link — no fill and no border, underlined in the accent. For an action that sits among real controls without competing with them, such as a reset beside a form's buttons, and it keeps the 44 pixel target a plain text link does not have.

Sizes

.theme-button--small — for dense surroundings: a card footer, a table row, a toolbar. Padding and font size shrink; the minimum tap target does not, so the visible box becomes smaller than the area that responds to a finger.
No size modifier — the size everything else is measured against.
Start the trial .theme-button--large — for the call to action of a hero or a landing section, where the button is the point of the section rather than one control among several.

Icon buttons and the close button

.theme-button--icon is square: the 44 pixel target in both directions, with a glyph as its only content. The glyph is decoration and hidden from assistive technology, and the name is aria-label on the button — an icon button with neither has no accessible name at all. It combines with every variant.

In order: the default, --secondary and --ghost, each combined with --icon, and --secondary once more with --large as well, which stays the same square: the size modifiers change the padding, and the icon button pins its box.
.theme-close — a component of its own rather than one more button modifier: no fill, no border, no label, and a negative margin that lines up the glyph, not the invisible target around it, with the content edge. The cross is two borders, so it survives forced colours mode. It belongs in a dialog or panel header; the Interactive section shows it in the dialog.

States

Two of the states a button has cannot be put into markup: no attribute freezes a pseudo-class. They are named here so that a reader knows they exist and can reach them, because a state nobody can see is a state nobody reviews.

:hover — point at this button. Background, border and text colour move to the component's own hover tokens; nothing about the box changes, so the button does not shift the layout under the pointer.
:focus-visible — press Tab until focus lands here. The ring is not the button's own rule: it is declared once for every focusable element in the reset, as an outline plus the focus-ring shadow token, so it looks identical on a link, an input and a button.
:disabled — the control spelling. The button is dimmed to the disabled opacity, the cursor turns to "not allowed", and the browser stops both the click and the focus by itself.
Revoke access [aria-disabled="true"] — the link spelling, styled identically. A link has no disabled attribute, so this one is announced as disabled and looks disabled but still takes focus and still follows its target: the template that renders it has to withhold the target as well.
Disabled combines with every other modifier, because it changes opacity and cursor only and leaves the token layer alone.
[aria-pressed="true"] — a toggle that is on. It takes the filled default, so it shows on --secondary and --ghost, the variants a toggle is drawn in; a filled button has no further step to show and should not be a toggle. An attribute rather than a class, like disabled, because it is what a screen reader announces. Pressing this one changes nothing: the state is the one a template would render.
[aria-busy="true"] — working. A spinner before the label, and the label says what is happening, because the spinner tells a screen reader nothing. Busy does not stop a click, so it is paired with aria-disabled. With reduced motion requested, the spinner stands still.

Link and control

The component is used for both an <a> and a <button>, and the two do not start out alike: a control arrives with a border, a background, a font of its own and a centred label from the browser, a link with none of those and an underline instead. Each pair below is the same class on both elements, so any difference left is a gap in the component.

Anchor .theme-button on <a> and on <button>.
Anchor .theme-button--secondary on both, where the border is the variant and a stray browser border would show immediately.
Anchor .theme-button--ghost on both, the hardest of the three: with no fill and no border of its own, anything the browser supplies is the only thing visible.

Button group

.theme-button-group is the row itself. It wraps rather than overflowing, because these labels are translated and a German one is routinely half again as long as the English it was measured on.

Save and publish

.theme-button-group--attached is one control in several parts: the buttons join edge to edge, only the outer corners stay round, and the row does not wrap, because a segmented control broken over two lines is two controls. The button whose border means something right now — hovered, focused or pressed — takes the shared edge. These three are static: pressing one changes nothing, aria-pressed is the state a template would render.

Badges

A badge is a status marker, not a control: it is never clickable and it never carries an action. It has two axes that are set independently — a severity, and a fill. The severity classes write only the raw accent and tint of the badge, --solid writes only the rendered background and foreground, so neither the order of the classes in the markup nor the order of the rules in the stylesheet changes the result.

Soft fill — the default. A tinted background with the accent as text, quiet enough to sit inside a card title or a table cell without pulling the eye off the content.
