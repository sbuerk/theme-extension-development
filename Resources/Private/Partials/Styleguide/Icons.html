Styleguide section "icons": the icons the theme itself draws, by name, and the sizes an icon takes. Contract: "components/_icon.scss" and "Classes/ViewHelpers/IconViewHelper.php". Every icon on this page comes out of "theme:icon", like everywhere else in the theme. The ViewHelper is plain Fluid, which is why this section renders in the visual suite as well - see "docs/development/icons.md". The list below is the set the templates use, not the set that ships: the whole Font Awesome Free solid set is there, and a gallery of it comes with the editor's icon picker. "IconUsageTest" holds this list to the icons the templates actually render, and the number below to the number of files shipped. The icons in the table are decoration: the name next to each is the content. The one labelled icon further down is the exception it demonstrates.

Icons

Every icon is one of the 2001 icons of Font Awesome Free in the solid style that ship with the theme, inlined as SVG by <theme:icon name="…" />. None is drawn by hand, none comes from a webfont or over the network. Pick an icon by its name, the file name below Resources/Public/Icons/FontAwesome/Solid/.

Sizes

An icon is a square one em wide, so it is as large as the text it sits in and needs no size of its own. A component that gives icons a slot — the alert, the close button, the icon button — sets --theme-icon-size on the slot instead. The same icon, in the text roles of the theme:

Eyebrow, 12 pixels

Body text, 16 pixels

Lead text, 20 pixels

Display

Wider icons keep the square: sun is 576 units wide against 512 high and is scaled to the width, so it comes out a little lower than moon.

Decoration, or an image with a name

Without a label an icon is decoration, rendered with aria-hidden="true": the text next to it, or the aria-label of the button around it, is what a screen reader announces. With label="…" it becomes role="img" named by that label — for the rare icon that is the only thing telling a reader something.
